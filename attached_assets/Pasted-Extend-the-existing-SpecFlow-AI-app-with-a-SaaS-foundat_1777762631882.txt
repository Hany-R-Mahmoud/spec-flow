Localization:
Add full English and Arabic localization.

Requirements:
- Use translation keys for all practical user-facing UI text.
- Do not hardcode visible labels directly in components where avoidable.
- Language preference persists locally.
- English uses LTR.
- Arabic uses RTL.
- Set document dir based on language.
- Mirror layout appropriately for RTL.
- Use logical CSS properties where possible, such as start/end, text-start/text-end, margin-inline, padding-inline, ms/me utility equivalents.
- Localize navigation, buttons, statuses, empty states, validation messages, settings labels, chart labels, dashboard metrics, workflow phases, story statuses, export labels, and auth UI.
- Keep emails, Jira keys, JSON, CSV, URLs, and code-like content LTR even inside Arabic UI.
- Arabic must feel intentionally RTL, not just translated text.

    defaultStoryTemplate: string
  }
