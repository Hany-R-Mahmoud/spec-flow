# Team Decisions

This folder is the durable home for team agreements, resolved discussions,
decisions, changes, and important project updates.

## Belongs Here

- architecture decisions
- product or UX decisions
- API or data contract changes
- workflow or process agreements
- team conventions
- deprecations or migration decisions
- important discussion outcomes

## Does Not Belong Here

- temporary chat
- unresolved brainstorming
- personal notes
- duplicated issue tracker content

## How To Add A Decision

1. Copy `decision-template.md` for larger decisions, or add a row to
   `decision-log.md` for small decisions.
2. Use status `Proposed`, `Accepted`, `Superseded`, or `Deprecated`.
3. Link related issues, PRs, docs, meetings, chats, or commits.
