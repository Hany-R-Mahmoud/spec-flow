# SpecFlow AI Demo Kit

Source: `docs/manus/reports/raw/demo-artifact-pack.md`

Use this as approved demo scaffolding. Keep claims factual and avoid unsupported
metrics.

## Demo Narrative

SpecFlow AI turns rough product input into review-ready delivery artifacts:
clarification questions, PRD sections, epics, stories, quality warnings, and
exports.

## Approved Demo Scenarios

| Scenario | Audience | Shows |
|---|---|---|
| Real-time notification system | Engineering managers, technical founders | Technical constraints, quality warnings, export readiness |
| User authentication redesign | Product managers, design leads | Ambiguity handling, scope narrowing, migration questions |
| Analytics dashboard | PMs, founders, engineering leads | Clear input to structured PRD, epics, stories, and review flow |

## Five-Minute Demo Shape

1. Paste rough input into a new breakdown.
2. Show clarification questions and explain why missing decisions matter.
3. Generate PRD, epics, and stories.
4. Review quality warnings and readiness scores.
5. Preview export path and explain Jira/GitHub handoff.

## Claim Guardrails

Supported:

- transforms rough product input into structured delivery artifacts
- generates clarification questions
- produces PRD sections, epics, stories, and acceptance criteria
- flags quality warnings
- supports export surfaces for Jira/GitHub handoff

Unknown / verify:

- exact time savings
- generation accuracy metrics
- customer adoption
- production integration reliability
- pricing or go-to-market claims

Do not claim:

- eliminates PMs
- creates 100% accurate specs
- saves a specific number of hours
- used by named companies
- production-ready integrations unless verified in the target environment
