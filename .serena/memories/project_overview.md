SpecFlow AI is a pnpm monorepo for a product workflow app that turns rough product input into structured breakdowns, stories, review output, and export-ready handoff. Main runtime surfaces: `artifacts/specflow-ai` React+Vite+TypeScript frontend, `artifacts/api-server` Express 5 API, shared packages in `lib/` for OpenAPI spec, generated React client, generated Zod contracts, and Drizzle DB schema. Auth via Clerk, persistence via Supabase Postgres, deploy on Vercel. Important docs: `README.md`, `docs/overview.md`, `docs/architecture.md`, `docs/project-structure.md`, `docs/local-development.md`, `docs/ai-agent-guide.md`, `docs/key-flows.md`, `graphify-out/GRAPH_REPORT.md`. Graphify report says main frontend workflow centers around `runGeneration()`, session state, adaptive intake, step skills, and toast/download helpers.
