# Settings Center

Settings surface for SpecFlow AI explored with Open Design.

## Summary

Compact full-page preferences UI for controlling app-wide experience without changing the main IA.

## Captured Controls

- Appearance: Theme, Density
- Notifications: In-app alerts, Email notifications, Review requests, Agent updates
- Keyboard shortcuts: Command palette, Project switcher, Notifications, Toggle density
- Sessions: Show progress bar, Show timestamps, Default view
- Exports: Default format, Include metadata

## Layout Notes

- Full-page centered layout, max-width 800px
- Sections stacked vertically with clear group boundaries
- Uses existing tokens only
- No new colors, no new theme system

## Open Design Handover Notes

- Theme and density controls match the existing app patterns.
- Keyboard shortcuts are displayed read-only for now.
- Remaining exploration questions: auto-save, shortcut editing, reset defaults.
