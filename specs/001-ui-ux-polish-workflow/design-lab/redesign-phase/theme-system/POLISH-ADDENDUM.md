# Theme System Polish Addendum

This addendum captures the final polish pass for the SpecFlow AI Agent Control Room theme system.

## Fixed

- Light-mode inactive nav contrast now meets WCAG AA.
- Light-mode sidebar section dividers are visible again.
- Light-mode progress track is legible against the canvas.

## Final refinement to keep

- Dark-mode session cards should read as lifted surfaces, not flat panels.
- Use a slightly softer card border in dark mode plus a subtle shadow to separate session cards from the canvas.
- Keep the card treatment calm and operational. No glow, no theatrics, no extra decoration.

## Explicitly unchanged

- Accent palette: cyan, teal, amber, red.
- Status-dot behavior.
- Typography scale.
- Theme toggle behavior.
- Sidebar breakpoint.
- App shell structure and IA.
- KPI cards, approval queue, and prompt-chain layout.

## Design intent

The system should still feel like one product with two equally polished themes. Light mode is crisp and operator-like. Dark mode is mission-control-like. Neither theme is a fallback.
