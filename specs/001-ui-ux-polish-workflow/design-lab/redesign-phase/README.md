# Redesign Phase

Tracked outputs from the Open Design redesign pass for SpecFlow AI.

Contents:

- `DESIGN.md` - approved Precision Ops design system generated from the Open Design desktop app.
- `specflow-ai-design-preview.html` - local preview artifact from the same run.
- `theme-system/` - dual light/dark Agent Control Room theme-system notes and polish addendum.
- `feature-catalog.md` - running inventory of explored redesign surfaces.
- `settings-center/` - Settings Center notes from Open Design.

Use this folder as the source of truth for the next Open Design iteration and for any follow-up design comparisons.
